

This is a fake website emulating a dog service company. 
I am using this repo to explore the NextJs framework, especially to test the server side rendering and to create a small backend in the same project. 

To start the server, first copy the .env.local.example as .env.local and fill it with your own information. 

Then run one of the following commands
  
    "dev": "npm run  dev",
    "build": "npm run build",
    "start": "npm run start",
    "lint": "npm run lint"
